# Netflix Clone 🎬

A responsive Netflix-inspired frontend clone built using HTML, CSS, and JavaScript.

## Features
- Responsive UI
- Navigation bar
- Movie banner section
- Hover effects
- Netflix-style design

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Note
This project focuses on the frontend UI and does not include backend or authentication functionality.
